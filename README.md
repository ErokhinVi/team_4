# Raiffeisen Bank — AI workshop, team repo

An AI workshop at Raiffeisen Bank. The format is vibe-coding with Claude
Code (or Codex).

This repository is one team's territory. Several teams work in parallel —
each team in its own repository — and the simulator + leaderboard live in
the separate organiser orchestrator repo. All teams solve the same task.
The bank is populated with simulated customers: every improvement or
breakage shows up in them — customers arrive or leave. A leaderboard
shows every team's score.

The team is three service blocks (`retail`, `cib`, `backend`), one
participant per block. The team's three participants commit to the same
shared branch of this repo and an AI assistant helps them.

Roles and blocks — see `TEAM.md`, rules — `RULES.md`. For organisers,
setup, deploy details and the workshop day — see the orchestrator repo
(`SETUP.md`, `RUNBOOK.md`, `ORGANIZER.md`).
